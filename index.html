About this site

Original 3D objects and interface built for Peter’s portfolio. The objects are conceptual illustrations; project facts come from Peter’s master profile and project documentation. Value Indiana and CityLink are SingularX products. The walkthrough uses Value Indiana product screenshots and report pages shared publicly by SingularX, plus a CityLink public-page image and a labeled illustrative JobHawk example. The Votify case study uses team repository screenshots. Votify screens are the team’s work; Peter worked on the backend.

References: Bokoko’s miniature room for the diorama treatment, and Bruno Simon’s portfolio for exploring work through objects. No source code or models were copied from either site.
